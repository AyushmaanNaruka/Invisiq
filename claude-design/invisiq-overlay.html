Why does my useEffect run twice on mount in React 18?
💭 Reasoning
The double-invoke is StrictMode in dev mounting, unmounting, then remounting to surface missing cleanup…

In React 18, <StrictMode> intentionally double-invokes effects in development only to help you catch missing cleanup. It does not happen in production.

Return a cleanup function so the effect is safe to run twice:

tsx 
useEffect(() => {
  const id = setInterval(tick, 1000);
  // cleanup makes the double-run harmless
  return () => clearInterval(id);
}, []);
